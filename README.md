## Vercel

Bu proje Vercel'in guncel Flask zero-configuration destegiyle deploy edilebilir.
GitHub'a bu dosyalarin tamamini yukleyip Vercel'de Import > Deploy yap.
Ekstra vercel.json, api klasoru veya gunicorn start command gerekmez.
